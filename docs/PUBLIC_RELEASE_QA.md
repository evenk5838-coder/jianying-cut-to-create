## 本地生产构建检查

- TypeScript / Vite 构建通过；最终 11 / 11 项浏览器回归通过（26.3 秒）。
- 桌面 1440×900、手机 390×844：五个入口逐一打开；核对标题、图像、场景，确认不显示其他功能详情。无横向溢出。
- 返回按钮与 Escape 均恢复原板块的滚动位置及键盘焦点。弹层打开期间背景影片暂停。
- 浏览器允许时自动低音量播放；拒绝时保持真实关闭状态，一次点击可开启。关闭或选择静音探索后停止，并记住关闭偏好。
- 同期口播与配乐联动、取消缓冲、媒体加载失败以及减少动态效果均回归。
- 模拟音乐加载失败时，错误提示不会被 pause 事件错误覆盖，且影片与详情仍可浏览。

自动化使用本机 Chrome 153 / Playwright，macOS Apple M1 Pro、16 GB。手机为尺寸模拟，未替代 iOS / Android 真机测试。详情截图在 qa/public-release/。
